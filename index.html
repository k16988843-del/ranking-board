① データを読み込む(全員の画面に反映されます)

  1. Chromeで最強キャラランキングの公開ページ(game8.jp/battlecats/207051)を開きます。
  2. キーボードの F12(Macは option + command + J)を押すと、画面の横か下に「コンソール」が開きます。
  3. 下の黒い枠の「コードをコピー」を押し、コンソールに貼り付けて Enter。
    ※「貼り付けないで」という警告が出たら、コンソールに allow pasting と入力して Enter してから、もう一度貼り付けてください。
  4. 「◯体をコピーしました」と出たら成功です。このページに戻り、下の入力欄に貼り付けます。
    ・最初の1回は「読み込む」。新キャラが増えたときは「新しいキャラだけを足す」を押します(今の最終案・みんなの意見・ランクの説明は、そのまま残ります)。

使い方

        
    
          
  1. 「自分のボード」で、最初に名前を入れます(次から、入れ直す必要はありません)。
    2. 
          
  2. 「最終案を自分のボードにコピー」を押す
    3. 
          
  3. アイコンをドラッグ＆ドロップして、指定のランクにキャラを動かせます
    （アイコンをタップしてランクを選択することでもキャラを動かせます）
    4. 
          
  4. 「みんなの意見」で、自分の意見が出ているか、見られます。
    5. 
        

        
動かさなかったキャラは、「今のままでよい」とは限りません。人数は、目安として見てください。

      


      

        
3つのタブ

        
    
          
  • 自分のボード: あなた専用のボードです。ここで動かしても、ほかの人のボードは変わりません。動かしたキャラが、あなたの意見として「みんなの意見」に出ます。
    • 
          
  • みんなの意見: 誰かが動かしたキャラが、一覧で出ます。誰が、どのランクにしたいかが分かります。意見が多い順に並びます。
    • 
          
  • 最終案: 決める人が使う、全員で1つを共有するボードです。ここを動かすと、全員の画面が変わります。
    • 
        

      


      

        
アイコンの動かし方

        
    
          
  • ドラッグ(パソコン): アイコンをつかんで、移したいランクの行まで動かして、離します。画面の上や下の端に近づけると、自動でスクロールします。
    • 
          
  • クリック(タップ): アイコンをクリックすると、移動先のランクを選ぶ窓が出ます。画面の外のランクにも、1回で移せます。
    • 
          
  • 長押し(スマホ): アイコンを少し長く押すと、指についてきます。そのまま移動先の行まで動かして、離します。
    • 
          
  • 動かしたキャラは、オレンジ色の枠になって、「元:◯◯」と出ます。元の場所に戻すと、意見は消えます。
    • 
          
  • 「名前の表示 ON/OFF」で、キャラの名前を出したり、消したりできます。
    • 
        

      



      

        
ランクの追加・入れ替え・説明文

        
    
          
  • 追加: ランク名を入れて、どの行の下に入れるかを選び、「ランクを追加」を押します。全員の画面に出ます。
    • 
          
  • 入れ替え: 「最終案」のタブで、各行のラベルの「▲」「▼」を押すと、行を上下に動かせます。順番は全員で共有です。
    • 
          
  • 削除: 追加したランクで、空のものは、「削除」で消せます。
    • 
          
  • 説明文: 各ランクの行の上の薄い文字を、クリックすると、そのランクの説明(1〜2行)を書けます。全員の画面に出ます。
    • 
        

      


      

        
気をつけてほしいこと

        
    
          
  • このボードのURLは、身内だけに配ってください。URLを知っている人は、誰でも動かせます。
    • 
          
  • 「最終案」「ランクの追加」「説明文」「リセット」は、誰でも操作できます。決める人だけが使う運用にしてください。
    • 
          
  • うまく動かないときは、画面右上が「みんなと同期中」になっているか、見てください。赤いときは、インターネットの接続を確かめて、ページを読み込み直してください。
    •
